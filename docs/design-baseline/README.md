# Design baselines

## Post-series reference — August 9, 2026

The approved DES-09 post-series reference set lives in `2026-08-09/`. It captures the
nine durable product routes in the seeded, single-user simulation environment at
1280×800 and 390×844. Each route was captured only after its page heading was visible,
network activity had settled, and motion was reduced. The 18 files use the route name
plus `-1280.png` or `-390.png`.

These images are visual source evidence. They do not identify or claim the current
hosted deployment. DES-09 changed no application markup or styles and did not regenerate
the frozen Overview or Reports DOM hashes.

## Before-series reference — July 22, 2026

"Before" reference screenshots captured from the post-SET-29/SET-35, pre-DES-series
source via the local dev server in simulation mode with e2e seed data:
nine durable routes at 1280x800 and 390x844, plus the collapsed desktop rail and
the mobile drawer. These are the review baseline for the DES packets and the
starting point for DES-09's approved post-series reference set.
